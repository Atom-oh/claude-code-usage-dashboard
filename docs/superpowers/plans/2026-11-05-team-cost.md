# Team Cost View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show per-team Claude spend on the Cost page (summary cards, team bar and trend, team table) with "No team" for cost without team evidence.

**Architecture:** Two new routes reuse existing machinery. `/api/cost/by-team` is a `costSummary`-shaped counter query with a session → team join (`sessionTeamsSql`), folded by a generalized `foldCostSummary`, plus per-team users/sessions/requests. `/api/cost/by-team-daily` adds a `team` dimension to `costByModelDailySql` and `foldModelCostCells` (same per-session scopes and top-N fold as the user trend). Cost.jsx renders one new section from those two responses.

**Tech Stack:** Node ESM + Express (`node:test`), ClickHouse SQL, React + Vitest.

**Spec:** `docs/superpowers/specs/2026-11-05-team-cost-design.md`

## Global Constraints

- Spend is Claude `reported_cost` from counters via `incFlat`/`incBucket`; never sum cumulative samples. Keep `known_reported_cost` / `reported_partial` semantics; all-unknown is `null`, not 0.
- Channel basis: `filterCond({ ...filters, excludeUnknown: false }, …)` for both new routes (team cost is a total-type metric). An explicit `group` filter still applies.
- Team per session: `sessionTeamsSql(["claude"], since)`; `team` null/'' is "No team". Never guess a team.
- Reconciliation: Σ team `known_reported_cost` (including No team) = Σ `costSummary` groups' `known_reported_cost` for the same range/filters.
- Trend top-N: `TEAM_TREND_TOP = 8`; teams outside it fold into one residual row (`team: null`, `rest_teams: n`); No team (`team: ""`) is never folded.
- Sessions = distinct `SessionId` with in-window usage (not `claude_code.session.count`).
- Requests = `api_request` events in `otel_logs` over `[from, to)` for those sessions.
- UI copy (Korean): section title `Team cost`; residual label `Other`; no-team label `No team`; subtitle must state the basis matches `Total cost` (unknown channel included).
- Routes go through `route()` with `team` allowed (default) and `client` as the other Cost routes; bound parameters only.

## Review Focus

1. A team filter (`team=X`) on `/api/cost/by-team` returns only X's row (and no No team row) — Task 1 test.
2. A session whose logs carry no team but whose counters carry cost lands in No team, and the totals still reconcile with `costSummary` — Task 1 SQL test.
3. An `unknown`-channel session's cost appears in its team's row — Task 1 SQL test.
4. More than 8 teams: the trend keeps 8 + `Other` + No team while the table lists all — Task 2 SQL test and Task 3 render test.
5. A team whose reports are all missing shows `unavailable` (null), not `$0`, and is excluded from the "Share of spend with a known team" numerator — Task 1 fold test and Task 3 render test.
