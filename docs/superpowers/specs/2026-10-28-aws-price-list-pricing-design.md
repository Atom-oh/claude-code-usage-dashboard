# AWS Price List as a live rate source

Status: approved by the user 2026-10-28 (apply immediately, label the source, refresh at build
time and at runtime). Amends ADR-017; ADR-009/013 contracts are unchanged.

## Problem

Rates live in hand-maintained code tables: `pricing.js` `BASE_PRICING` (Claude, global
base + regional multiplier) and `codexPricing.js` `DEFAULT_CODEX_PRICING` (AWS list rates by
scope/context tier). A model absent from both is unpriced. For non-Anthropic models used
through Claude Code (ADR-017 amendment) that makes the session-model factor unknown, so
user/model totals become partial (e.g. `kimi-k3`, `zai.glm-5.3`, `openai.gpt-6.1-terra` on
2026-10-28). Every new Bedrock model or price change currently needs a code change and
redeploy.

## Decision

Add the AWS Price List API (`pricing:GetProducts`, endpoint `us-east-1`) as a rate layer.

Precedence, highest first, per model key:

1. Operator overrides: `PRICING_JSON` / `CODEX_PRICING_JSON` (negotiated rates) — unchanged.
2. Runtime Price List fetch (latest successful refresh, in memory).
3. Build-time snapshot `dashboard/server/awsPriceSnapshot.json` (generated, committed,
   baked into the image; regenerated by `npm run prices:snapshot` before each image build).
4. Hand-maintained code tables (fallback when the API and snapshot lack a model).

A Price List entry replaces a lower layer only when it is complete for the scope it
provides (input, output, cache read, cache write; see mapping). Incomplete entries are
skipped and logged, never partially merged. When a fetched rate differs from the code table
by more than 2x, log a warning (still apply — the user chose live prices).

### Sources and mapping

Reference region `us-east-1`, On-Demand terms, USD, standard (non-flex, non-priority,
non-batch) tier. Rates normalized to USD per 1M tokens (`1K tokens` × 1000).

- `AmazonBedrockFoundationModels` (Anthropic, OpenAI marketplace models). `model` is a display
  name; usagetype suffix encodes bucket/scope/tier, e.g.
  `USE1-MP:USE1_input_tokens_global_standard-Units`,
  `..._cache_write_tokens_1h_standard`, `..._output_tokens_long_ctx_global_standard`.
  Display name → key: `Claude Fable 5.1` → `claude-fable-5-1`; `OpenAI GPT-6 Astra` →
  `openai.gpt-6-astra` (provider prefix `openai.`, version dots kept for OpenAI).
- `AmazonBedrock` (Bedrock-hosted third-party models). usagetype carries the model id, e.g.
  `USE1-moonshotai.kimi-k3-mantle-input-tokens-standard`,
  `USE1-zai.glm-4.7-input-tokens`. Key = the id between `USE1-` and the bucket suffix with
  `-mantle` removed; `global-standard` suffix = global scope.
- Bare ids seen in telemetry (`kimi-k3`) resolve to a unique `<vendor>.<id>` match
  (`moonshotai.kimi-k3`); ambiguous matches stay unpriced.

Claude table (`pricing.js` shape `{input, output, cacheWrite, cacheWrite1h, cacheRead}`,
global base): from the `global_standard` rows; `cacheWrite` = 5m write, `cacheWrite1h` = 1h
write. The existing regional multiplier keeps applying to regional ids.

Codex table shape (`{short_context_limit, regional:{short,long}, global:{short,long}}`):
regional = non-global `standard` rows, global = `global_standard`; `long` from `long_ctx`
rows, else equal to `short`. `cacheWrite` = the only write bucket present (30m for OpenAI),
else 5m. `short_context_limit` is not in the Price List: keep the code table's value; for a
new model with `long_ctx` rows and no known limit, use flat short rates and log it (known
underestimate for long requests).

### Runtime

- New `priceCatalog.js` owns the merged view and exposes getters used at call time:
  `claudePricing()` (replaces module-level `PRICING` in `pricing.js`) and `codexPrices()`
  (replaces the module-level `parseCodexPricing(process.env.CODEX_PRICING_JSON)` consts in
  `clientMetrics.js`, `codexLogAggregates.js`, `codexInsightsLogs.js`, `nonAnthropicCost.js`).
  Function signatures that accept a `prices` argument keep it (tests inject tables).
- `awsPriceList.js`: fetch both service codes with `@aws-sdk/client-pricing`
  (`GetProducts`, `regionCode=us-east-1` filter, paginated), parse to both shapes.
  Pure parser exported for tests; fixtures from real responses (trimmed) under `test/fixtures/`.
- Startup: load snapshot synchronously; start the first refresh in the background (never
  block startup or a request). Refresh every `AWS_PRICE_REFRESH_HOURS` (default 12); failures
  keep the last good layer and log. `AWS_PRICE_LIST=off` disables runtime fetch (local/dev,
  tests).
- Response caches may serve rates up to their TTL; no cache flush on refresh.
- `/api/config` adds `pricing.priceList: { source: "runtime"|"snapshot"|"code", fetchedAt,
  models }` — metadata only, no rates.
- Rows priced from a Price List layer carry `price_source: "aws_price_list"` where the API
  already emits `price_source`; the Cost page help text names the source and `fetchedAt`.

### Build time

- `npm run prices:snapshot` (server) writes `awsPriceSnapshot.json` with `fetchedAt`,
  service codes, and parsed tables (sorted keys, stable output). The deployment runbook and
  `/deploy` skill run it before `docker build`; a failure aborts with a message (the old
  snapshot remains usable for an explicit `--skip-price-snapshot`).

### Infrastructure

`infra/dashboard.tf`: add `pricing:GetProducts` (Resource `*`; the action has no
resource-level scoping) to the existing `dashboard_bedrock` IRSA role policy. No network
change: the pod already reaches AWS APIs through existing egress.

## Non-goals

- No ClickHouse persistence (the dashboard uses a read-only ClickHouse user).
- Reported Claude spend (`reported_cost`) is unchanged; Price List only affects
  computed diagnostics, ADR-017 estimates, and Codex estimates.
- Not an invoice: no Flex/Priority/Batch tiers, discounts, or Savings Plans.

## Tests

- Parser: fixture → expected tables for Claude Fable 5.1, OpenAI GPT-6 Astra (must equal the
  current hand table), Kimi K3 (`AmazonBedrock`), GLM 4.7; incomplete entry skipped;
  flex/priority/batch ignored.
- Catalog precedence: env override > runtime > snapshot > code; incomplete runtime entry
  does not shadow code; refresh failure keeps last good.
- Bare-id alias: unique match resolves, ambiguous stays unpriced.
- Integration: `nonAnthropicCost.foldFactors` prices `kimi-k3` once the catalog has it.
- `AWS_PRICE_LIST=off` in the test env; no network in tests.
