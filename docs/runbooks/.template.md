# Runbook: <Operation>

## Purpose

State the dashboard, collector, ClickHouse, or review-panel symptom this procedure resolves.
Write in English; keep API fields, commands, paths, and identifiers as implemented.

## Prerequisites

Name the target context/account, required tools and permissions, and any backup or
maintenance window. Separate repository declarations from verified deployed state.
Never include credential values or commands that print them.

## Procedure

Give ordered, executable commands from a stated working directory. Define non-secret
parameters before use. Link to an existing runbook for shared setup instead of copying it.
State stop conditions before mutations and distinguish local checks from live operations.

## Verification

Specify observable success criteria, including failures or unknown results that block
progress. Record the source revision and the date/scope of any actual operational check.
Source reconciliation alone is not evidence that a deployment or migration succeeded.

## Rollback

Give a tested recovery path, its preconditions, and any irreversible step. State limitations
explicitly; do not present a ledger edit, image rollback, or retry as a data restore.

## Sources

Link to the Terraform, SQL, scripts, or application code that owns this procedure.
