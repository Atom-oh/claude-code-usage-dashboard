API contracts and cost detail

Use the shared client endpoints for combined views. Keep source coverage, exact filters and the meaning of each denominator visible.

Updated October 24, 2026 · Describes source behavior; verify your installed revision.

Authentication

In OIDC mode, telemetry APIs use session cookies. Unauthenticated API requests return JSON 401 with authentication_required and a login URL. Unsafe session requests require the configured Origin and permission.

Basic mode requires both configured credentials. Unauthenticated local development is an explicit opt-in; an empty password configuration is not a production login mode. Device ingestion uses its own bearer-token gate.

GET /api/session reports role, permissions and the short expiresAt; optional refreshExpiresAt is the absolute login deadline. It never returns raw IdP tokens.

Time and filters

ParameterContract
from, toUse ISO 8601 with timezone and from < to. Default range is two days; default cap is 90 days. Deployment settings can change them.
clientShared overview: all, claude or codex; disabled sources are rejected.
backendClient views: all, bedrock-mantle, bedrock-runtime, anthropic or unknown.
user, modelExisting partial filters. Model normalization and identity expressions depend on the endpoint.
userExact, modelExactShared overview only: exact row identities for drilldowns. Verify returned applied_filters. Codex insights rejects these parameters.
intervalHoursWrapped routes require a finite value in (0,744]. Shared overview supports bounded subhour resolution; read actual bucket_hours and effective_range.
groupClaude inferred session channel, not the emitting client or an SSO authorization group.
projectEndpoint-specific, not a universal filter. Consult the complete API reference before applying it.

Cost/Trends expose ten- and thirty-minute options only through 24 hours. Older windows use hourly rollups; arbitrary finer requests can fall back to a supported native bucket.

EndpointUse
GET /api/clients/overviewTotals, client/model/user breakdowns, timeseries and coverage. Optional modelTime=1 returns model timeseries.
GET /api/clients/overview?view=costSame cost, token coverage, population and bounds; skips unused project/tool/operational diagnostics. Omitted fields are not zero.

Model user shares divide known user costs by the selected model's known cost subtotal. Unknown prices are disclosed; an unknown or zero denominator yields no percentage.

Codex recorded-completion efficiency

completion_usage describes deduplicated usage-bearing completion logs, with basis="recorded_completions". It does not claim every HTTP attempt or session in the selected window has complete telemetry.

FieldDenominator and boundary
cache_hit_rate, cache_write_shareValidated cache-read/cache-write subsets divided by canonical input tokens within recorded completions.
reasoning_shareValidated reasoning subset divided by canonical output tokens in that cohort.
tokens_per_completionCanonical tokens divided by recorded completion count; observed token subtotals cannot replace missing canonical components.
cost_per_completionKnown completion costs divided by all recorded completions, retaining partial-price disclosure.
cost_per_identified_sessionOnly completions with a conversation ID contribute to both the cost numerator and distinct-session denominator.
unidentified_completionsCounted separately and excluded from the identified-session cost unit.
completenessReports missing usage/session evidence, limited aggregate families, incomplete tokens and available whole-window request/session counts.

Missing components, impossible subsets, zero denominators, all-unknown prices or limited usage can still produce null. Existing whole-window HTTP request/session ratios keep their stricter guards. The UI exposes them in an expandable section.

EndpointContract

Management and downloads require OIDC collector:manage (analyst/admin). Viewer/demo access is denied. Device endpoints do not use usage-range filters; their responses and downloads are no-store.

Health and errors

/healthz is liveness; /readyz gates readiness. Protected /api/health/data reports ingestion freshness. A live process does not establish fresh telemetry.

Malformed filters fail before querying. Refresh service failures can return 503 with Retry-After: 5; expired or invalid credentials require login. Bounded query admission can reject overload instead of creating unbounded database work.
