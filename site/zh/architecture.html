采集：客户端 → 已存储的观测数据

Claude Code 和 Codex 将受支持的信号导出到本地 Collector。已注册的设备通过经过身份验证的摄取网关和中央 Collector 将数据发送到 ClickHouse。设备凭据与浏览器登录凭据相互独立。

读取：已登录用户 → 仪表板结果

组织登录会提供已配置的角色。API 会先应用时间、客户端和受支持的筛选条件，然后再返回使用情况和诊断视图。请查看成本依据和覆盖范围：屏幕中可能显示已知的小计，也可能显示不可用的信号。

采集路径和信任边界 · 日志、指标和追踪数据有何不同

关联用户、任务与span

用户详情会选择精确的遥测身份和时间范围。/api/users/tasks会列出在有效范围内开始的任务；拖动使用量图表可缩小范围，而单击数据点可选择一个区间。/api/users/tasks/detail会返回所选任务的轨道、Span 和基于证据的成本说明。

客户端任务与计时用量与成本
Claude Codeinteractionspan用于标识任务和持续时间。LLM、工具及权限等待span构成时间线；观测到的智能体 ID 构成泳道。LLM span中的令牌数；如果有日志，则关联其中报告的请求成本，否则使用适用的定价计算。显示的成本依据可能混合多种来源。
Codex包含会话 ID 和唯一轮次 ID 的轮次用于标识任务。持续时间取观测到的span时间窗口；仅提供主泳道。与轮次时间窗口关联的、具有用量信息的唯一完成日志提供令牌数和 AWS 列表价估算。匹配的完成记录值也会显示在采样span上。

Codex 任务用量是关联完成记录的视图，并非额外的记账来源。未关联的完成记录会单独报告；缺少匹配采样span的调用可能不会计入累计成本带。Analytics Trace 预览会独立读取诊断span。

任务详情查询只选择允许列表中的元数据。界面会遮蔽身份信息，且不呈现原始提示词、命令或路径；此显示策略不构成 API 访问控制。追踪数据的保留期限为 90 天，与用量汇总数据分开管理。

可选的设备路径使用 /api/ingest/v1/{logs,metrics,traces}。浏览器会话 Cookie 无权授权数据接收。集中式 Collector 持有 ClickHouse 写入凭证；PC 使用可撤销的设备凭证。

由组织者预先配置的 Workshop 环境使用单独配置的采集路径。未经迁移，请勿将设备套件叠加到已准备好的 Collector 上。

数据接收信任边界与限制

保留信号语义

信号解释
Claude 计数器遵循序列身份、累计/增量时间属性、基线和重置规则。切勿将累计导出值相加作为用量。
Codex 完成日志按完整身份去重，并且只对包含用量信息的完成记录计价一次。中间流记录不会再增加一份用量总计。
Codex 指标与追踪将其用作诊断信息。不要把其中观测到的令牌数或成本加到完成日志用量中。
缓存令牌和推理令牌在定义如此时，将其视为输入/输出的子集。再次将它们加到规范总量中会造成用量重复计数。
证据缺失或受限保留已知小计并标记为部分数据。对于受影响的严格比率，应不予提供并说明原因；缺失不代表为零。

数据边界 · Codex 可观测性

客户端、后端与会话渠道

采集和 API 路由会识别发出信号的客户端。提供方来源信息和模型证据有助于判断后端；仅凭模型标识符无法识别客户端。

Claude 会话渠道分类器会区分 bedrock、enterprise 和 unknown。观测到的 Bedrock 模型证据以及组织/模型回退规则会在会话范围内生效。此分类并非仪表板用户的 SSO 角色。

定价/后端逻辑会规范化区域/地理范围的 Bedrock 模型标识符和裸提供方 ID。请保留不受支持的范围和未知价格，不要假设每个模型 ID 都有对应价格。Codex 没有企业版 A/B 行。

后端定价决策

减少查询工作量，同时保持总量不变

  • view=cost会选择共享概览中的有界成本配置，省略未使用的诊断数据。
  • profile=effort会选择仅基于 Codex 日志的详情，并跳过无关的指标/追踪查询。
  • Codex 日志聚合会先在 ClickHouse 中按完整身份压缩事件，再传输数据。聚合系列限制仍会显示。
  • Single-flight 缓存和有界准入机制会共享重复工作，同时保留筛选条件身份、截止时间和过载错误。

这些机制可以减少工作量，但无法保证支持 140 个用户并发。请在目标安装环境中测量具有代表性的筛选条件多样性、冷缓存流量、数据接收情况和查询延迟。

成本查询性能

仪表板访问与设备访问

OIDC 会验证已签名的身份，并将明确的组值映射到 viewer、analyst 或 admin。获授权的查看者可以读取整个安装环境的遥测数据；这不是按员工隔离行数据。

设备令牌允许采集遥测数据和下载安装程序包，但不允许浏览器访问。每个令牌由不同主体单独持有，并可过期或撤销。遥测归属信息由客户端提供；SSO 会话或令牌所有权均不会自动验证遥测电子邮件地址。

PII 遮蔽是一项显示功能，不是 API 访问控制。采集过滤器会移除已知内容字段，但无法检测放入其他受支持元数据中的任意机密。

部署边界

仪表板镜像包含 Web 界面和 API。在所有平台上，ClickHouse、其数据库模式和 OTel Collector 都是独立组件。当前 Compose 文件未包含 Collector；EKS Terraform 会复用现有集群依赖项。ECS/EC2 需要经过审核的基础设施、凭据、网络、探针和持久化配置；Lambda 需要将应用适配到其运行时。

必需组件 · 比较托管选项

数据库模式生命周期、应用镜像、Collector 策略和运行时选项各有独立的部署状态。构建成功或 Terraform 验证通过，都不能证明线上部署或迁移已成功。
