User guide

Learn what the dashboard shows, how to explore it, and when a result needs more evidence.

Features depend on your installation, permissions and collected data. This guide explains each control and retains useful on-screen labels from the Korean-first application. Verified against the v1.8.0 source.

Start here

The dashboard summarizes telemetry sent by enabled Claude Code and/or Codex clients. It helps you explore observed usage, estimated or reported cost, activity and diagnostic signals. It does not show an invoice or prove employee productivity, code quality or return on investment.

  1. Open your organization's dashboard and sign in as directed. In organization login, a viewer can read permitted telemetry; analyst and administrator roles may also use chat and manage their own collector devices. Installation status is an administrator function. Features also require the deployment to enable and configure them. Ask your operator if you cannot sign in or a menu is absent.
  2. If this is a new installation, an operator sets up collection and access. A permitted device owner can follow Collector setup, start a new client session and make a request. Allow time for data to arrive; receipt alone does not establish complete collection.
  3. Choose a client under 클라이언트 if the selector is present, and choose a period at the top of the page. Open Overview. Read the cost basis, effective period, totals and any partial or missing-data notices.
  4. Follow your question: use Cost for a model or user breakdown, Trends for a change over time, or Users for a user and their tasks. Return to the same source and period when comparing results.

On a narrow screen, open the menu (메뉴 열기) at the top. Choose a page; the drawer closes after navigation. Close it with its close button, the backdrop or Escape.

Controls and reading results

Source and filters

클라이언트 selects all enabled clients, Claude Code or Codex. It appears when more than one is enabled. The nine menus initially use a shared view with comparable columns. Select Claude Code and Claude 상세 보기 to open its detailed pages; 공통 보기 returns to the shared view. Only enabled clients appear.

In shared views, 백엔드 selects the observed transport/provider path, such as Bedrock Runtime, Bedrock Mantle, Anthropic or unknown. It is separate from the client and model. Claude detail instead may offer bedrock and enterprise inferred session channels; these are not client identities, authorization groups or a Codex comparison. Unclassified sessions can appear in totals but be excluded from channel comparisons. A single-channel installation may hide the channel control.

사용자 검색 and 모델 검색 match partial text. A 팀 selector appears when team values are available. Team is a client-supplied attribute and applies only where indicated on screen; the warning lists exceptions, including adoption, user detail charts and Codex diagnostics. In Claude detail, 프로젝트 appears only when project fields are confirmed: enter the exact table value. It applies only to Usage's project, entry point, permission-mode and approval-source cards. Read page notices: some measures do not honor every filter. Changing modes clears incompatible filters.

Time, refresh and charts

Choose a day preset, 이번 달 (this month), or 기간 직접 선택 (choose a period). In the picker, 날짜 uses UTC calendar days; 날짜·시간 accepts local browser dates and times to the second, with the end exclusive. Choose 적용 to apply. Date presets and buckets use UTC; chart labels, precise times and exports display in your browser's time zone. Requested and effective periods can differ because data is grouped and recent ingestion is allowed time to arrive. Read the effective-period notice before comparing.

Use 지금 새로고침 for an immediate refresh or choose an automatic interval, including off. During a background refresh the previous result may remain visible; a failure explicitly says so. When a new period is loading or fails, do not treat old data as the new period. Shared Cost and Trends offer 추이 해상도 (trend resolution): up to ten-minute buckets for periods of at most a day, with coarser options for longer periods.

Hover a chart to read values and use the legend to identify series; some legends let you focus a series. On supported time-series charts, drag across a time interval to change the whole page's period. Clear the custom-period chip with its × or choose a preset to reset. Categorical charts do not zoom. In user detail, a point click can select a single time bucket for the task list; a drag changes the page period. Chart actions can be unavailable while a result is stale.

Tables, exports and privacy

Where column headings offer sorting, click a heading to change order. Some tables have their own search or other selectors; the top filter bar is not a universal search of every table. Tables show the returned rows rather than providing a general page control. Collector devices have a separate 기기 더 보기 (load more) control. Where a CSV button appears, it exports the displayed columns and sorted rows, not an automatic export of every dashboard result. It is disabled for empty or stale results. Some charts offer their own CSV download. Some shared tables initially show 20 rows when there are more; use 전체 …행 보기 to expand it, and CSV follows the visible rows. Model-cost trend charts offer 누적/기본 display modes, a data table and selectable legend series; use 모두 보기 to restore them. Horizontal scrolling may be needed for wide tables.

Masking can hide parts of identities on screen and in supported exports, but it is not an access-control boundary. User detail and task information can still be sensitive. Share only with authorized recipients, check the content and range first, and never put collector tokens or personal/customer data in screenshots, links or public material.

What a number means

—, unavailable (미수집 or 미산정) and an empty result are not the same as an observed zero. A partial label (부분합) means a known subtotal, not a complete total. A positive total does not prove complete telemetry. Loading, request errors, a shortened range and stale refresh warnings each need separate attention. Hover the help icon and read the card subtitle for its population and denominator.

For Anthropic models, Claude detail spend remains report-based and calculated token-price values are opt-in diagnostics. Shared overview may fill missing reports with a separately labeled estimate. Claude non-Anthropic models and Codex use AWS list-price estimates. Mixed totals retain their bases and unknown prices. None is an invoice or guaranteed billing bound. Observed token subtotals may omit components; ratios require their complete denominators. Codex runtime metrics and traces are diagnostic feeds and must not be added to completion-log usage or cost.

Productivity

Shared view: When available, the token-economics section shows a cost equation, change drivers, unit-cost and request-efficiency trends, model economics, observed outcome-unit cost and eligible example users. It needs the installation's session-turn data to be ready; an unavailable section is not zero. Below it are eight sections: (1) client summary, (2) observed model efficiency and cache/reasoning shares, (3) activity, (4) code results, (5) permission decisions by tool, (6) tool results, (7) response and wait, and (8) activity-index top users. Even where present, these observations and arbitrary activity indices do not establish productivity, quality, time saved or causal ROI.

Users

Shared view: Compare observed users, sessions and cost per user across clients, then use the user table. The same identified user can be combined across selected clients; per-client composition retains each cost basis. Client-level unique counts can overlap and must not be added to get a total. Select an identified user to open detail; unidentified rows cannot open it.

The detail has period summary and time charts, a separately loaded 90-day UTC daily-session heatmap, client-specific tool/permission information where available, and the task list. The heatmap's daily values are observed bucket session counts, not a distinct-session total. Detail waits for matching parent bounds; point selection narrows the task list to a bucket and dragging changes the page range. Use 전체 조회 기간의 작업 to return the task list to the full period; close the detail to return to the table.

Claude detail: Read channel summaries, eligible activity-index rankings, model-family average cost per user, observed user activity, and user-by-tool and user-by-Skill tables. Select a user row for detail and tasks. A user's observed activity is not a personal performance evaluation.

In Claude detail, the separate 사용자 검색 field filters observed-activity rows. Opening a user includes all enabled clients in the detail; the selected inferred channel applies only to its Claude areas.

Analytics

Shared view: If chat is permitted, ask a question above the diagnostic panels. Below it, compare client signals and first-token time, then inspect model/backend diagnostics, project-tag usage and observed signal coverage. Project tags are client-supplied and are not billing projects.

When Codex is selected, Codex 상세 offers 런타임·메트릭 and Trace. The first shows session-start settings, a metric-name search, collected metrics and event coverage. Collector setup (수집기 설치)

This menu requires organization login and device-management permission, typically analyst or administrator, plus enabled device ingestion. It manages the signed-in person's devices. A viewer should ask an authorized operator for help. Follow your organization's approved installation instructions.

  1. Choose Linux or macOS and read the preparation instructions. Enter a device name and register it.
  2. Copy the one-time device token when shown and keep it secret. Copy the displayed installation command, run it on that device and enter the requested user ID and token at the terminal prompt. Do not put the token directly in the command or share it.
  3. Open a new terminal, start a new Claude Code or Codex session and make a request. Use the on-page receipt verification steps and check 내 기기 (my devices) for recent receipt.
  4. Refresh the list, load more devices if offered, and inspect registered, expired or revoked state, expiry and last receipt. To stop a device, choose 해지 and confirm 해지 확인. Reconnecting requires a new token. If a token-reuse warning appears, revoke and register again.

Active devices renew automatically starting seven days before expiry when configured by the current installer. Expired or revoked devices need a new token and installation. Logging out does not stop device collection. Recent receipt does not prove all usage was collected. See installation and operations for operator details.

Tasks and Trace

Find a task

  1. Open Users, select an identified user and locate 작업 목록 · 상위 20개 (task list, top 20). It initially uses the matching effective user-detail period. Click a point in a supported user chart for one bucket, or drag a period to update the page and list.
  2. Choose 토큰 많은 순 (most tokens), 비용 높은 순 (highest cost), 서브에이전트 많은 순 (most subagents) or 느린 순 (slowest). The list shows at most 20. Claude cost ranking considers at most the top 100 token candidates when indicated, so a costlier task outside that pool can be missing.
  3. Read start time, client, model, workflow, calls, subagents, token composition and observed subtotal, cost basis and duration. Select a workflow badge to narrow to that Claude workflow run; clear its filter to return. Select a row or start time to open the task.

Tracing is optional, so this list is always partial. Tasks without trace evidence do not appear. The UI treats ranges beginning more than 90 days ago as beyond trace retention. Codex tasks are turns; their token and cost values are linked estimates from completion logs in the same conversation and time interval. Unattached or limited records are called out.

Read the task detail

The timeline shows a main lane and observed subagent lanes; repeated agent types are numbered and shaded separately. LLM calls grow darker with larger input context; gray marks tools, red marks permission waits and dotted marks subagent creation. Select a call or other span to read its model, timing, tokens, cost, effort, attempt and available attributes. Missing values remain uncollected; Codex attempts are not supplied. Spans without start time cannot be placed on the timeline.

The stacked cost band shows cumulative observed cost by lane; hover to inspect a point. Unpriced gaps and unlinked Codex completions are not a complete cost history. The context chart shows observed per-call input context and compaction points; select a call there to inspect it. Codex can show a context-window share when known; Claude does not report the window size here. Missing calls are omitted, not zero.

왜 많이 썼나 (why so much) highlights available observations such as repeated context, lane share or retries; these are clues, not proven causes. 모델별 호출 (calls by model) lets you select a row to highlight matching LLM calls and select again to clear it. 세션 환경 shows observed Claude session MCP server status and loaded plugins, not a per-call inventory. Codex does not supply these session events. Tool-definition counts and token sizes are not available.

Use the task-link control to copy or select a share link. It contains the task and its time bounds, and a recipient still needs dashboard access; share it only with an authorized person. A missing, expired or mismatched task may not open. Detail is capped at the newest 5,000 spans. When truncated, the UI warns and withholds the KPI row, cost band and explanatory summary; Claude whole-task/lane totals are also withheld. An incomplete trace is not evidence that no other calls occurred. Close the overlay to return; closing a shared task link goes to Users.

AI assistant

When chat is configured, authenticated, permitted and backed by a confirmed read-only data connection, use Ask Claude or the question box on Analytics. In organization login, viewers do not have chat permission; analyst and administrator access is conditional on deployment configuration. A visible control alone does not guarantee the service is ready.

Type a usage question and send it, or choose an example. Analytics groups examples under cost, adoption/activity, users/tools, productivity and anomaly detection; after a conversation begins they remain available as a horizontal strip. Most presets use the selected period's length in days; the recent-usage preset explicitly asks for three hours, so state an exact time window, client or other scope in your question when needed. Do not assume every dashboard filter is applied to a chat question. Follow up in the conversation and check the answer against the underlying dashboard and coverage notices. SQL answers do not automatically reproduce Codex completion deduplication and pricing or the non-Anthropic Claude cost adjustments used by dashboard cards. Verify their population and cost basis before comparing totals.

The floating window can be resized, expanded, restored and closed; closing stops an in-progress answer and retains the conversation while the widget remains mounted. Answers may contain up to three supported line or bar charts. Hover for values and open 데이터 보기 to see the chart's data table. Read the source, cost basis, effective period, partial and row-limit labels: SQL-result chart coverage may be unconfirmed. The assistant may answer without a chart; it does not offer a general chart-data selector or chart download control. Use a dashboard table's CSV button where provided. Avoid submitting secrets or sensitive personal data in questions.

Troubleshooting

  • No rows: Check source, time and filters; try a new client session. An empty period can mean no matching observations, not zero organization-wide use.
  • Unavailable or partial: Check the card's coverage and cost basis. Some signals, prices, project fields, session-turn data or traces require additional collection or setup. Do not fill gaps with zero or infer completeness from a subtotal.
  • Old or failing data: Read refresh and freshness warnings, retry and check your login. If a refresh fails, retained data is explicitly previous. Ask an operator to investigate collection and permissions.
  • Missing task or link: Check the user, effective period, trace retention, enabled client, optional tracing and truncation notices. Workflow filtering and top-N bounds can hide other tasks. A share link requires access and the complete link.
  • Missing control: Client enablement, schema, role, feature configuration and collected events affect what is shown. In particular, device setup and status require permission, and chat additionally requires its own configured service and read-only connection.

For specialist work, see installation, operations, architecture and API contracts.
