ccdash アプリケーションの画面を、合成 API データを使ってローカルでキャプチャしました。ID には予約済みの example.test アドレスを使用し、コストは架空のものです。実運用のテレメトリーは使用していません。

Task Trace の画像は、合成テストフィクスチャを使って、現在の React コンポーネントから2026年11月14日にキャプチャしました。現在のキャプチャには、正確な時間範囲の選択、ドラッグによるタスクへの移動、デバイスのインストール、エージェントのレーン、モデル呼び出し、セッション環境が表示されています。ソースのリビジョンと画像のチェックサムはメディアの来歴情報に記載されています。

現在の48秒の動画は、画面上の英語テキスト、Amazon Polly のナレーション、英語の字幕トラックを使って、2026年11月14日に作成しました。説明には控えめな背景音楽が添えられています。画面には合成フィクスチャを使った実際の React コンポーネントを使用し、動画の表示ラベルは openai.gpt-6-luna で翻訳しました。このキャプチャによって、アプリケーションに英語ローカライズが追加されるわけではありません。

ガイドの韓国語、日本語、簡体字中国語への翻訳には openai.gpt-6-luna を使用しています。翻訳の来歴情報には、ソースと出力のチェックサムが記録されています。

書体：同梱の Noto Sans。フォントライセンス。

ビジュアルのレンダリングには HyperFrames 0.7.77 と GSAP 3.14.2、音声の合成には Remotion 4.0.542、Chromium、FFmpeg を使用しました。Amazon Polly では英語の Matthew ニューラル音声を使用しています。背景音楽は、外部の録音やサンプルを使わずに作成した、再現可能なオリジナルのサイン波パッド曲です。構成と絵コンテでは、英語版動画について説明しています。GSAP は標準ライセンスを適用し、Remotion には独自のライセンス条項があります。
