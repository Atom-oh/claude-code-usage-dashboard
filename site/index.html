What changed

Cost drilldowns

User and model selections open filtered details. Model shares use the known cost subtotal and disclose missing prices.

Codex completion efficiency

Cache and reasoning ratios, tokens per completion, and estimated cost per identified session have explicit denominators and coverage.

Device installation

A macOS/Linux package configures both clients. Per-device tokens, revocation and a confirmed legacy macOS migration keep setup manageable.

Configurable SSO

Map signed OIDC groups to application roles. Enable a fixed login lifetime of up to 30 days when the identity provider supports the refresh contract.

Keep the dimensions separate

Client identifies the emitting application. Backend describes the observed or inferred provider path. Model identifies the model. A model name alone does not identify the coding client.

The Claude bedrock/enterprise comparison is an inferred session-channel view. It is separate from dashboard login and is not a Codex enterprise A/B comparison. One user can appear in multiple channels.

Analytics can answer additional questions through the guarded, read-only query path when enabled. Its availability depends on role, model access and deployment configuration.
