Claude Code + Codex · 제품 문서

화면으로 익히는 ccdash 사용 가이드

기간과 사용자를 선택하고, 작업의 개별 호출까지 따라가 보세요. 비용 변화와 토큰 효율, 도구 사용을 실제 화면과 단계별 설명으로 확인할 수 있습니다.

자세한 단계별 안내 보기 아키텍처 보기

처음 사용하는 독자, 분석가 및 운영자를 위한 안내서입니다. 메뉴는 활성화된 클라이언트, 권한 및 설치된 버전에 따라 달라집니다.

분석할 항목을 선택하세요

01 · 사용자 및 추적사용자 한 명의 작업 따라가기사용자 → 기간 → 작업 → 에이전트 → 개별 호출. 02 · 비용 및 효율성비용 변화 설명하기비용 기준, 모델별 비중, 단위 비용, 토큰 및 캐시. 03 · 도구 및 MCP도구 활동 이해하기도구 호출, 권한, 스킬, MCP 및 세션 컨텍스트.

화면에 표시되는 숫자의 출처

데이터 수집과 대시보드 액세스에는 서로 다른 경로가 사용됩니다. 다이어그램은 선택적 기기 데이터 수집 경로와 인증된 읽기 경로를 보여 줍니다. 주최자가 준비하는 워크숍 데이터 수집에는 별도로 구성된 경로를 사용할 수 있습니다. 이 그림은 OIDC 로그인과 기기 수집을 사용하는 구성 예입니다.

데이터 수집: 클라이언트 → 저장된 관측 데이터

Claude Code와 Codex는 지원되는 신호를 로컬 Collector로 내보냅니다. 등록된 기기는 인증된 수집 게이트웨이와 중앙 Collector를 거쳐 ClickHouse로 데이터를 보냅니다. 기기 자격 증명은 브라우저 로그인과 별개입니다.

읽기: 로그인한 사용자 → 대시보드 결과

조직 로그인이 구성된 역할을 제공합니다. API는 결과를 반환하기 전에 시간, 클라이언트 및 지원되는 필터를 적용합니다. 비용 기준과 데이터 범위를 확인하세요. 화면에는 확인된 소계가 표시될 수도 있고, 사용할 수 없는 신호가 표시될 수도 있습니다.

데이터 수집 경로 및 신뢰 경계 · 로그, 메트릭, 트레이스의 차이

처음 방문하셨나요?

  1. 조직의 대시보드를 열고 로그인합니다. 주소와 접근 권한은 담당자에게 문의하세요. 지금 보고 있는 공개 사이트는 문서 사이트입니다. 계정 및 권한을 참조하세요.
  2. 클라이언트와 기간을 선택합니다. 활성화된 모든 클라이언트와 최근 작업이 포함된 기간으로 시작하세요. 표시된 시간대와 데이터가 도착했는지 확인하세요.
  3. Overview를 읽습니다. 확인된 비용, 관측된 토큰, 세션 및 사용자를 비교하세요. 결론을 내리기 전에 부분 또는 사용 불가 상태를 나타내는 표시를 읽으세요.
  4. 궁금한 점에 맞는 메뉴를 선택합니다. 아래 메뉴 안내를 사용한 다음, 해당 메뉴의 단계별 안내를 따르세요. 일반 보기는 클라이언트를 비교하고, Claude 세부 보기에는 Claude 전용 보기가 추가로 제공됩니다.
  5. 상세 정보를 확인하고 관련 보기를 공유합니다. 지원되는 경우 모델, 사용자 또는 작업을 살펴보세요. 내보내거나 공유할 때 선택한 기간과 필터를 고려하세요.

대시보드를 읽고 싶습니다

공통 컨트롤부터 확인한 다음 필요한 메뉴의 안내서를 여세요. 기존 배포 환경에 대한 접근 권한이 필요합니다.

코딩 클라이언트를 연결하고 싶습니다

권한이 있는 경우 수집기 설정을 사용해 기기를 등록하거나, 운영자에게 설치 안내를 요청하세요.

서비스를 운영합니다

설치 및 운영 안내에 따라 배포, 로그인 구성, 수집 및 복구를 진행하세요.

대시보드의 모든 메뉴

전체 사용자 안내서에서 각 메뉴의 섹션과 작업, 그리고 일반 보기와 Claude 세부 보기의 차이를 설명합니다.

메뉴다음 작업을 하려면 여기서 시작하세요…
Overview관측된 사용량, 확인된 비용 및 데이터 범위의 전반적인 상황을 파악합니다.
Executive도입 및 비용 요약을 간결하게 읽고, 지표의 한계를 확인합니다.
Trends시간에 따른 변화를 찾아보고 조사할 기간을 좁힙니다.
Productivity직원 성과로 간주하지 않으면서 단위 경제성, 비용 요인 및 관측된 활동을 살펴봅니다.
Usage토큰 구성 및 지원되는 도구 사용 세부 정보를 살펴봅니다.
Users관측된 사용자를 비교하고, 사용자 세부 정보를 열고, 선택한 기간의 작업을 찾습니다.
Cost클라이언트, 백엔드, 모델 또는 사용자별 지출을 분석하고, 사용 가능한 비용 산정 기준을 확인합니다.
Reliability보고된 오류, 지연 시간 및 사용 가능한 진단 신호를 조사합니다.
Analytics선택한 클라이언트에서 사용할 수 있는 상세 분석과 지원되는 진단 탭을 살펴봅니다.
Collector 설정(수집기 설치)권한이 있는 경우 기기를 등록하고 Collector를 설치하며 기기 수집 자격 증명을 관리합니다.
설치 상태권한이 허용되는 경우 배포, 데이터베이스 및 로그인 준비 상태를 확인합니다.

다음 항목도 다룹니다: Task Trace 및 공유 작업 링크, 선택 사항인 AI 어시스턴트, 계정 컨트롤 및 도움말, 실용적인 조사 워크플로.

숫자를 해석하기 전에 의미를 확인하세요

  • 확인된 비용은 청구서가 아닙니다. Claude가 보고한 지출과 지원되는 정가 추정치에는 각각의 비용 산정 기준이 유지됩니다. 가격 정보가 누락되면 소계가 부분 값일 수 있습니다.
  • 사용 불가는 0과 다릅니다. 관측된 토큰 소계, 완전한 토큰 구성 요소 및 진단 범위는 서로 다른 질문에 답합니다. 합계가 양수라고 해서 수집이 완전하다는 뜻은 아닙니다.
  • 활동은 관측 결과입니다. 세션, 도구 및 비용 비율만으로 직원 성과, 절약된 시간 또는 생산성의 인과 관계를 입증할 수는 없습니다.

데이터 범위 및 표시 상태 읽기 · API 계약 · 측정 정의

기간을 설정하고 차트를 사용하세요

UTC 기준 날짜를 사용하거나 날짜 선택기의 날짜·시간 탭에서 브라우저 현지 시간 기준의 정확한 시작 및 종료 시간을 설정하세요. 종료 시각은 범위에 포함되지 않습니다. 표시된 실제 적용 구간을 확인하세요. 서버 롤업과 데이터 수집 유예 기간이 계속 적용됩니다.

지원되는 시계열 차트를 드래그하여 페이지 기간을 좁히고, 초기화 컨트롤을 사용해 원래 범위로 돌아가세요. 사용자 세부 정보에서는 작업 목록이 해당 범위를 따릅니다. 한 지점을 클릭하면 하나의 구간이 선택됩니다. 범주형 차트에서는 시간 범위를 선택할 수 없습니다.

모든 필터, 새로고침, 차트, 표, 내보내기 및 공유 컨트롤

사용자에서 실제 작업으로 이어서 살펴보기

Users를 열고 사용자를 선택한 다음 선택한 기간의 작업 목록을 살펴보세요. 작업을 열면 Task Trace가 표시됩니다. 여기에서 기본 및 하위 에이전트 레인, 호출, 확인된 비용, 토큰 컨텍스트, 모델 및 사용 가능한 세션 환경을 확인할 수 있습니다.

추적 기능은 선택 사항입니다. Claude 상호작용과 추적된 Codex 턴은 서로 다른 증거를 제공하며, 누락된 호출, 속성 또는 가격은 계속 사용 불가 상태로 표시됩니다. 작업 목록과 세부 정보에는 명시적인 제한이 있습니다.

작업 및 Trace 전체 안내 · 작업 API의 제한 사항 · 누락된 작업 문제 해결

작업 사용량과 진단 추적을 구분하세요

Analytics의 Codex 진단 Trace 탭은 Task Trace와 별개인 미리 보기입니다. 이 탭은 스팬과 사용 가능한 메타데이터를 보여줍니다. 진단 지표와 스팬은 완료 로그 합계에 사용량이나 비용을 더하지 않습니다.

Analytics 탭 및 클라이언트별 차이 · AI 어시스턴트 및 자체 추론 표시

각 차원을 구분하세요

클라이언트는 Claude Code 또는 Codex를 식별하고, 백엔드는 공급자 경로를 설명하며, 모델은 모델을 식별합니다. 모델 이름만으로는 이벤트를 발생시킨 클라이언트를 식별할 수 없습니다.

Claude의 bedrock / enterprise 비교에는 추론된 세션 채널이 사용됩니다. 이 채널은 대시보드 로그인과 별개이며 Codex enterprise A/B 비교를 제공하지 않습니다.
