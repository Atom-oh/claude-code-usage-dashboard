토큰 비용 구조

Productivity는 비용 방정식(사용자 수 × 사용자당 세션 수 × 세션당 턴 수 × 턴당 요청 수 × 요청당 토큰 수 × 토큰당 비용)을 이전 기간과 비교해 보여주며, 요인 워터폴, 단위 비용 추세, 모델 비용 구조 및 결과별 비용도 표시합니다. 예시 사용자는 각 요인의 중앙값과 비교해 그래프로 표시됩니다. 운영자는 세션 및 턴 백필이 완료된 뒤 이 기능을 사용할 수 있습니다.

Task Trace: 모델, 워크플로 및 세션 환경

비용 설명에는 모델별 호출 및 비용이 나옵니다. 워크플로 실행 배지로 사용자의 작업을 필터링하고, 같은 유형의 서브에이전트에는 번호를 표시합니다. 세션 환경에는 연결된 MCP 서버, 로드된 플러그인 및 첫 호출의 컨텍스트가 표시됩니다.

서명된 OIDC 그룹을 애플리케이션 역할에 매핑하세요. ID 공급자가 갱신 계약을 지원하면 최대 30일의 고정 로그인 유효 기간을 설정할 수 있습니다.

사용자에서 Task Trace까지

  1. 시간 범위와 클라이언트 필터를 선택하세요. 날짜 선택기의 날짜 및 시간 탭에서 브라우저 현지 시간 기준으로 정확한 시간을 입력할 수 있습니다. 열기 사용자을 선택한 다음 사용자를 선택해 사용자 상세 (사용자 상세)를 여세요.
  2. 작업 목록에는 개요의 유효 범위에 해당하는 작업이 최대 20개까지 바로 표시됩니다. 사용자의 사용량/비용 추세를 드래그하면 페이지와 작업 목록의 범위가 함께 좁혀집니다. 점을 클릭하면 구간 하나가 선택되고, 재설정 컨트롤을 사용하면 전체 기간으로 돌아갑니다. 토큰, 비용, 서브에이전트 또는 기간별로 정렬하세요. 워크플로 배지를 선택하면 해당 실행의 작업만 표시됩니다.
  3. 작업을 선택해 열기 작업 상세 (Task Trace). 토큰, 비용 기준, LLM 호출, 서브에이전트 및 관측된 기간을 확인하세요.
  4. 타임라인 막대를 클릭해 해당 호출 또는 도구를 살펴보세요. 다음에서 행을 선택하면 모델별 호출 (모델 호출), 해당 LLM 막대가 강조 표시됩니다. 다시 선택하면 강조 표시가 해제됩니다. Escape 또는 닫기 (닫기)를 눌러 닫으세요.
보기읽는 방법
에이전트 레인먼저 기본 세션이 표시되고, 그 뒤에 관측된 서브에이전트가 표시됩니다. 어두운 LLM 막대일수록 입력 컨텍스트가 큽니다. 회색 표시는 도구, 빨간색 표시는 권한 대기이며, 점선은 관측된 에이전트 생성 이벤트를 연결합니다.
누적 비용레인 색상은 확인된 호출 비용을 누적해 표시합니다. 마우스를 올려 특정 시점의 정보를 확인하세요. 일치하는 스팬이 없는 Codex 완료 항목은 작업 총비용에 포함될 수 있지만 밴드에는 표시되지 않을 수 있습니다.
선택한 스팬사용 가능한 모델, 토큰 구성 요소, 비용 기준, 시간 및 도구 또는 권한 메타데이터를 살펴보세요. 원시 프롬프트, 명령 및 경로는 표시되지 않습니다.
비용이 많이 든 이유캐시 읽기 비중, 컨텍스트 증가, 레인 비용 비중, 고비용 호출, 재시도 또는 권한 대기와 관련된 규칙을 입력 데이터가 있을 때 데이터에 기반해 설명합니다. 패널에는 모델별 호출 수, 확인된 비용 및 비용 비중도 표시됩니다.
모델 호출레인, 호출 수 및 확인된 비용별로 모델과 호출 출처를 비교하세요. 행을 강조 표시하면 타임라인 강조만 바뀌며 합계는 바뀌지 않습니다.
세션 환경최근 상태별 MCP 서버, 스킬·에이전트·명령 수를 포함한 로드된 플러그인, 첫 호출의 입력 컨텍스트가 표시됩니다. OpenTelemetry는 도구 정의의 개수나 크기를 보고하지 않습니다.

Claude 작업은 상호작용 스팬을 나타내며, Codex 작업은 추적된 턴을 나타내고 토큰 및 예상 비용에 연결된 완료 로그를 사용합니다. 현재 Codex에는 기본 레인 하나만 있으며 서브에이전트 수는 수집되지 않습니다. Trace 수집은 선택 사항이므로 작업 목록은 대시보드 활동의 일부만 보여줍니다. Trace 보존 기간은 90일이며, 그보다 오래된 추세 구간에서는 작업 목록을 열 수 없습니다.

Codex 진단 Trace 확인

Codex를 선택한 상태에서 Analytics를 열고 Codex 상세 화면의 Trace 탭을 선택합니다. Trace를 펼쳐 span, 상위 ID, 모델, 도구, 소요 시간, 상태를 확인하거나 span 표를 CSV로 내보낼 수 있습니다.

이 미리 보기에는 최신 Trace 50개와 Trace당 최신 span 최대 200개가 표시됩니다. 통계는 표시된 span을 기준으로 합니다. 모델 필터는 모델 속성이 있는 span만 포함합니다. Trace가 너무 길거나 서로 충돌하는 경우 소요 시간 및 오류 합계가 표시되지 않을 수 있습니다.

진단 span은 대시보드 사용량이나 비용에 추가되지 않습니다. 위의 Task Trace는 Codex 완료 로그를 턴에 연결하며, Analytics의 Trace 탭은 별도의 진단 미리 보기입니다. Chat의 추론 및 SQL 단계는 또 다른 별도 화면입니다.

시간 범위 및 해상도 선택

기간 선택기를 열고 날짜 및 시간 을 선택해 브라우저 시간대 기준으로 초 단위까지 시작 및 종료 시간을 입력하세요. 종료 시간은 범위에 포함되지 않습니다. 공유 링크에는 선택한 모드와 UTC 경계가 유지되며, 달력 날짜 모드는 계속 UTC 날짜를 사용합니다.

선택한 범위비용 및 추세 컨트롤
최대 24시간10분, 30분, 시간별, 일별 또는 주별. 하루 보기에서는 시간별 해상도로 시작합니다.
24시간 초과시간별, 일별 또는 주별. 이틀 보기에서는 10분 해상도를 선택할 수 없습니다.

반환된 구간과 유효 시간 경계를 확인하세요. 정확한 시간을 입력해도 수집 유예 기간, 서버 양자화 또는 과거 롤업 정밀도는 바뀌지 않습니다. 단위 비용 차트에서 점선 구간은 사용할 수 없는 구간을 가로질러 관측된 끝점을 연결하는 시각적 가이드이며, 측정값이 아닙니다.

각 차원을 구분해서 보기

클라이언트는 이벤트를 내보낸 애플리케이션을 식별합니다. 백엔드는 관측되거나 추정된 공급자 경로를 설명합니다. 모델은 모델을 식별합니다. 모델 이름만으로 코딩 클라이언트를 식별할 수는 없습니다.

Claude의 bedrock/enterprise 비교는 추정된 세션 채널 보기입니다. 대시보드 로그인과는 별개이며 Codex 엔터프라이즈 A/B 비교가 아닙니다. 한 사용자가 여러 채널에 표시될 수 있습니다.

활성화된 경우 역할, 모델 액세스, 배포 구성에 따라 보호된 읽기 전용 쿼리 경로를 통해 Analytics에서 추가 질문에 답할 수 있습니다.
