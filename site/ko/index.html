  4. 필수 조건을 갖춘 EC2, ECS 또는 EKS를 선택하세요. Lambda를 사용하려면 애플리케이션을 Lambda 런타임에 맞게 수정하거나 포팅해야 합니다.

구성 가능한 SSO

서명된 OIDC 그룹을 애플리케이션 역할에 매핑합니다. ID 공급자가 갱신 계약을 지원하면 최대 30일의 고정 로그인 유효 기간을 설정할 수 있습니다.

사용자에서 Task Trace까지

  1. 시간 범위와 클라이언트 필터를 선택합니다. 사용자 또는 비용을 열고 사용자를 선택해 사용자 상세를 엽니다.
  2. 해당 사용자의 추세에서 버킷을 클릭합니다. 작업 목록에는 해당 버킷에서 시작된 작업이 최대 20개 표시됩니다. 토큰, 비용, 하위 에이전트 또는 소요 시간 기준으로 정렬할 수 있습니다.
  3. 작업을 선택해 작업 상세(Task Trace)를 엽니다. 토큰, 비용 산정 기준, LLM 호출, 하위 에이전트, 관측된 소요 시간을 확인합니다.
  4. 타임라인 막대를 클릭해 해당 호출이나 도구를 확인합니다. 모델별 호출에서 행을 선택해 일치하는 LLM 막대를 강조 표시하고, 다시 선택하면 강조 표시가 해제됩니다. Escape 또는 닫기(화면 닫기)를 눌러 닫습니다.
보기읽는 방법
에이전트 레인먼저 기본 세션이 표시되고, 그 뒤에 관측된 하위 에이전트가 표시됩니다. 색이 더 짙은 LLM 막대는 입력 컨텍스트가 더 큼을 나타내며, 회색 표시는 도구, 빨간색 표시는 권한 대기, 점선은 관측된 에이전트 시작을 연결합니다.
누적 비용레인 색상은 확인된 호출 비용을 누적해서 표시합니다. 마우스를 올리면 특정 시점의 정보를 확인할 수 있습니다. 일치하는 span이 없는 Codex 완료 기록은 띠에 나타나지 않더라도 작업 총계에 포함될 수 있습니다.
선택한 span사용 가능한 모델, 토큰 구성 요소, 비용 산정 기준, 시간 정보, 도구 또는 권한 메타데이터를 확인합니다. 원시 프롬프트, 명령, 경로는 표시되지 않습니다.
왜 많이 썼나입력 데이터가 있는 경우 데이터 기반 규칙을 통해 캐시 읽기 비중, 컨텍스트 증가, 레인별 비용 비중, 고비용 호출, 재시도 또는 권한 대기를 설명합니다. 이 항목은 왜 비용이 많이 들었는지 설명합니다.
모델 호출레인, 호출 횟수, 확인된 비용을 기준으로 모델과 호출 출처를 비교합니다. 행을 강조 표시해도 타임라인의 강조만 바뀌며 합계는 바뀌지 않습니다.

Claude 작업은 상호작용 span을 나타냅니다. Codex 작업은 추적된 턴을 나타내며, 연결된 완료 로그를 토큰과 예상 비용에 사용합니다. 현재 Codex에는 기본 레인 하나만 있으며 하위 에이전트 수는 수집되지 않습니다. Trace 수집은 선택 사항이므로 이 작업 목록은 대시보드 활동의 일부만 포함합니다. Trace 보존 기간은 90일이며, 그보다 오래된 추세 버킷에서는 작업 목록을 열 수 없습니다.

Codex 진단 Trace 확인

Codex를 선택한 상태에서 Analytics를 열고 Codex 상세 화면의 Trace 탭을 선택합니다. Trace를 펼쳐 span, 상위 ID, 모델, 도구, 소요 시간, 상태를 확인하거나 span 표를 CSV로 내보낼 수 있습니다.

이 미리 보기에는 최신 Trace 50개와 Trace당 최신 span 최대 200개가 표시됩니다. 통계는 표시된 span을 기준으로 합니다. 모델 필터는 모델 속성이 있는 span만 포함합니다. Trace가 너무 길거나 서로 충돌하는 경우 소요 시간 및 오류 합계가 표시되지 않을 수 있습니다.

진단 span은 대시보드 사용량이나 비용에 추가되지 않습니다. 위의 Task Trace는 Codex 완료 로그를 턴에 연결하며, Analytics의 Trace 탭은 별도의 진단 미리 보기입니다. Chat의 추론 및 SQL 단계는 또 다른 별도 화면입니다.

각 차원을 구분해서 보기

클라이언트는 이벤트를 내보낸 애플리케이션을 식별합니다. 백엔드는 관측되거나 추정된 공급자 경로를 설명합니다. 모델은 모델을 식별합니다. 모델 이름만으로 코딩 클라이언트를 식별할 수는 없습니다.

Claude의 bedrock/enterprise 비교는 추정된 세션 채널 보기입니다. 대시보드 로그인과는 별개이며 Codex 엔터프라이즈 A/B 비교가 아닙니다. 한 사용자가 여러 채널에 표시될 수 있습니다.

활성화된 경우 역할, 모델 액세스, 배포 구성에 따라 보호된 읽기 전용 쿼리 경로를 통해 Analytics에서 추가 질문에 답할 수 있습니다.
