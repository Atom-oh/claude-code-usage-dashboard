API 계약, 비용 및 Task Trace

정확한 식별자, 제한된 시간 범위, 명확한 신호 의미를 사용해 공통 클라이언트, 사용자 작업 및 Codex 진단 API를 이용하세요.

2026년 11월 14일 업데이트 · 소스 코드의 동작을 설명합니다. 설치된 버전을 확인하세요.

Task Trace API · 진단 Trace API

인증

OIDC 모드에서 텔레메트리 API는 세션 쿠키를 사용합니다. 인증되지 않은 API 요청은 authentication_required와 로그인 URL을 포함한 JSON 401 응답을 반환합니다. 세션을 사용하는 안전하지 않은(상태 변경) 요청에는 설정된 Origin과 권한이 필요합니다.

Basic 모드에서는 설정된 자격 증명 두 가지가 모두 필요합니다. 인증되지 않은 로컬 개발은 명시적으로 활성화해야 합니다. 비밀번호 설정이 비어 있는 상태는 프로덕션 로그인 모드가 아닙니다. 기기 데이터 수집은 자체 bearer 토큰 검증을 사용합니다.

GET /api/session은 역할, 권한 및 짧은 만료 시간인 expiresAt을 보고합니다. 선택 항목인 refreshExpiresAt은 절대 로그인 기한입니다. 원시 IdP 토큰은 반환하지 않습니다.

시간 및 필터

매개변수계약
from, to시간대가 포함된 ISO 8601 형식을 사용하며 from < to여야 합니다. 기본 범위는 2일이고 기본 한도는 90일입니다. 배포 설정으로 변경할 수 있습니다.
client공유 개요: all, claude 또는 codex. 비활성화된 소스는 거부됩니다.
backend클라이언트 보기: all, bedrock-mantle, bedrock-runtime, anthropic 또는 unknown.
user, model기존 부분 필터입니다. 모델 정규화와 ID 표현식은 엔드포인트에 따라 달라집니다.
userExact, modelExact공유 개요: 드릴다운에 사용하는 정확한 행 ID입니다. 반환된 applied_filters를 확인합니다. 작업 경로에는 userExact가 필요합니다. Codex 인사이트에서는 profile=tools일 때만 userExact를 허용하며, modelExact는 항상 거부합니다.
intervalHours래핑된 경로에는 (0,744] 범위의 유한한 값이 필요합니다. 공유 개요는 범위가 제한된 1시간 미만 해상도를 지원합니다. 실제 bucket_hours 및 effective_range를 확인합니다.
groupClaude에서 추론된 세션 채널이며, 발신 클라이언트나 SSO 인증 그룹을 뜻하지 않습니다.
project엔드포인트별 매개변수이며 보편적인 필터가 아닙니다. 적용하기 전에 전체 API 참조를 확인합니다.

비용/추세 보기에서는 최대 24시간 범위에서만 10분 및 30분 옵션을 제공합니다. 더 오래된 기간에는 시간별 롤업을 사용하며, 임의의 더 세밀한 요청은 지원되는 기본 구간으로 대체될 수 있습니다.

브라우저 선택기에서는 초 단위 정밀도로 현지 날짜와 시간을 입력할 수 있습니다. 공유 링크에는 ISO 형식의 from/to 경계와 UI 전용 rangeMode=time 표시가 포함됩니다. 이 표시는 API 필터가 아닙니다. 유효 경계는 여전히 각 엔드포인트의 양자화, 수집 유예 기간 및 롤업 규칙을 따릅니다.

공통 클라이언트 및 비용 엔드포인트

엔드포인트용도
GET /api/clients/overview합계, 클라이언트/모델/사용자별 분석, 시계열 및 데이터 범위를 제공합니다. 선택 항목인 modelTime=1은 모델 시계열을 반환합니다.
GET /api/clients/overview?view=cost동일한 비용, 토큰 범위, 모집단 및 경계를 제공합니다. 사용되지 않는 프로젝트/도구/운영 진단은 건너뜁니다. 생략된 필드는 0을 뜻하지 않습니다.
GET /api/clients/token-economics유효 기간과 직전 기간의 비용 방정식, 드라이버 분해, 단위 추세, 모델 경제성, 결과 비용 및 모범 사용자. 운영자가 마이그레이션 010 백필 후 SESSION_TURNS_READ_FROM을 설정할 때까지 값은 사용할 수 없습니다.
GET /api/codex/insightsCodex 완료 효율과 로그, 메트릭 및 Trace 진단 정보를 제공합니다.
GET /api/codex/insights?profile=effort비용/작업량 보기용 로그 전용 상세 정보입니다. 메트릭 및 Trace 범위는 not_requested입니다.
GET /api/cost/summary, /by-model, /by-user-model기존 Claude 전용 비용 경로입니다. 이를 여러 클라이언트를 합산한 총계로 취급하지 마세요.

모델별 사용자 비중은 알려진 사용자 비용을 선택된 모델의 알려진 비용 소계로 나눕니다. 알 수 없는 가격은 별도로 표시되며, 분모를 알 수 없거나 0이면 백분율을 제공하지 않습니다.

Codex 기록 완료 기준 효율

completion_usage는 사용량이 포함된 중복 제거 완료 로그를 설명하며, basis="recorded_completions"를 사용합니다. 선택한 시간 범위의 모든 HTTP 시도나 세션에 텔레메트리 데이터가 완전하게 기록되었다고 보장하지 않습니다.

필드분모 및 범위
cache_hit_rate, cache_write_share기록된 완료 건 내 정규 입력 토큰 중 검증된 캐시 읽기/쓰기 부분집합의 비율입니다.
reasoning_share해당 코호트의 정규 출력 토큰 중 검증된 추론 부분집합의 비율입니다.
tokens_per_completion정규 토큰을 기록된 완료 건수로 나눈 값입니다. 관측된 토큰 소계로 누락된 정규 구성 요소를 대체할 수 없습니다.
cost_per_completion알려진 완료 비용을 기록된 전체 완료 건수로 나누며, 부분 가격 정보임을 표시합니다.
cost_per_identified_session대화 ID가 있는 완료 건만 비용 분자와 고유 세션 분모 모두에 포함됩니다.
unidentified_completions별도로 집계되며 식별된 세션 기준 비용 단위에서는 제외됩니다.
completeness누락된 사용량/세션 증거, 제한된 집계 계열, 불완전한 토큰, 그리고 사용 가능한 전체 시간 범위의 요청/세션 건수를 보고합니다.

구성 요소 누락, 불가능한 부분집합, 0인 분모, 모두 알 수 없는 가격 또는 제한된 사용량이 있으면 결과가 여전히 null일 수 있습니다. 기존 전체 시간 범위 HTTP 요청/세션 비율에는 더 엄격한 검증 조건이 적용됩니다. UI에서는 해당 항목을 펼쳐 볼 수 있습니다.

완료, 데이터 범위 및 집계 제한의 전체 의미

Collector 및 기기 API

엔드포인트계약
GET /api/collector기능 상태, 구성된 공개 수집 엔드포인트, 버전, 플랫폼, 토큰 수명 및 installScriptUrl.
GET /api/collector/devices소유자 범위의 기기 목록으로, 페이지당 최대 50개입니다. 반환된 커서는 변경하지 않고 사용합니다.
POST /api/collector/devicesname 및 platform(darwin 또는 linux)으로 등록합니다. 토큰은 한 번만 반환됩니다.
DELETE /api/collector/devices/:id소유 기기를 폐기합니다.
GET /api/collector/package/:platform인증된 다운로드이며, 자격 증명은 포함되지 않습니다.
GET /api/ingest/install.sh기기 수집이 구성된 경우 공개 설치 스크립트입니다. 터미널에서 귀속 정보와 토큰을 입력하라는 메시지가 표시되며, 스크립트 자체에는 자격 증명이 포함되지 않습니다.
GET /api/ingest/package/:platformdarwin 또는 linux용 기기 bearer 인증 아카이브입니다. 기기당 시간당 다운로드 10회로 제한됩니다. 브라우저 세션이나 내장 토큰은 사용하지 않습니다.
POST /api/ingest/v1/{logs,metrics,traces}기기 bearer 토큰만 사용합니다. OTLP JSON/protobuf, 최대 2 MiB, 콘텐츠 압축은 지원하지 않습니다.

관리 및 수동 /api/collector/package/:platform 다운로드에는 OIDC collector:manage(분석가/관리자)가 필요합니다. 뷰어/데모 권한으로는 기기를 관리할 수 없습니다. 설치 스크립트와 기기 토큰 패키지 경로는 별도의 수집 경로를 사용합니다. 기기 엔드포인트는 사용량 범위 필터를 사용하지 않으며, 응답과 다운로드는 no-store입니다.

상태 확인 및 오류

/healthz는 활성 상태 확인용이고 /readyz는 준비 상태를 확인합니다. 보호된 /api/health/data는 데이터 수집 최신 상태를 보고합니다. 프로세스가 실행 중이라고 해서 최신 텔레메트리 데이터가 확보된 것은 아닙니다.

잘못된 필터는 쿼리 실행 전에 거부됩니다. 새로고침 서비스 오류는 Retry-After: 5와 함께 503을 반환할 수 있습니다. 자격 증명이 만료되었거나 유효하지 않으면 로그인이 필요합니다. 제한된 쿼리 허용 정책은 데이터베이스 작업이 무제한으로 늘어나는 대신 과부하 요청을 거부할 수 있습니다.

전체 경로 목록, 응답 필드 및 오류

사용자 작업 및 Trace API

사용자 상세 정보는 기본적으로 개요의 유효 기간을 불러옵니다. 차트를 드래그하면 페이지와 작업 목록이 업데이트되고, 지점을 클릭하면 하나의 구간이 선택됩니다. 개요 요청이 대기 중이거나 실패한 경우 이전 작업 목록을 현재 목록처럼 표시하지 않습니다.

세션 인증 텔레메트리 접근을 사용합니다. userExact는 요청한 시간 범위 내에서 작업의 텔레메트리 소유자를 선택하는 값이며, 대시보드 독자가 자신의 텔레메트리만 볼 수 있도록 제한하지는 않습니다.

엔드포인트요청 및 응답
GET /api/users/tasks필수 항목은 userExact와 선택한 범위의 from/to입니다. 선택 항목은 client, backend, Claude 전용 group, sort=tokens|cost|subagents|duration입니다. 작업은 최대 20개 반환되며, unattached_codex, 클라이언트별 coverage 및 partial=true가 포함됩니다. Claude 전용 workflowRunId 또는 workflowName을 지정하면 목록이 하나의 워크플로 실행으로 좁혀집니다.
GET /api/users/tasks/detail목록 행의 id, userExact 및 동일한 범위 경계가 필수입니다. task, lanes, spans, truncated, span_total 및 why를 반환합니다. 존재하지 않는 작업과 소유자/범위가 일치하지 않는 경우 모두 404를 반환합니다. Claude 작업에는 세션의 MCP 서버와 로드된 플러그인을 나타내는 environment도 반환됩니다.
  • 두 경로 모두 team을 거부합니다. 반환된 작업 ID를 변경하지 않고 전달합니다. 비활성화된 클라이언트나 잘못된 형식의 ID는 거부됩니다.
  • Claude 비용 정렬은 관측된 토큰 수가 가장 많은 작업 100개로 구성된 후보 풀을 정렬합니다. sort_candidates.limited를 확인합니다. 이 풀에 포함되지 않은 더 비싼 작업은 누락될 수 있습니다. Codex 턴은 정렬 전에 비용을 산정합니다.
  • 상세 응답은 최신 스팬을 최대 5,000개 반환합니다. Claude 상세 정보가 잘린 경우 전체 작업 및 레인 합계, 모델, why는 제공되지 않습니다. Codex 완료 이벤트에서 계산하는 작업 합계는 스팬 잘림에 영향을 받지 않습니다. 다만 잘린 경우 오버레이의 KPI 행과 비용 밴드는 숨겨집니다.
  • 스팬 속성은 허용 목록에 포함된 항목만 제공합니다. 토큰 구성 요소, 비용, 타이밍 또는 하위 에이전트 근거가 누락된 경우 사용할 수 없는 상태로 유지됩니다. 트레이싱은 선택 사항이므로 작업 응답은 항상 부분적입니다.

UI 둘러보기 · 전체 작업 필드, ID 검증 및 연결 규칙

Codex 진단 Trace 미리보기

기본 GET /api/codex/insights 프로필에는 traces, span 지연 시간 집계 및 coverage.traces가 포함됩니다. 최신 Trace 50개를 반환하며, 각 Trace에는 최신 span 최대 200개가 포함됩니다. 이 상한은 Task Trace 상세 보기의 5,000 span 상한과 다릅니다.

통계는 표시된 span을 설명합니다. 모델 필터는 모델 속성이 있는 span에만 적용됩니다. 잘림 또는 서로 충돌하는 span 식별자가 있으면 Trace 수준의 지속 시간/오류 통계와 상세 정보가 제공되지 않을 수 있습니다. 메트릭 또는 Trace의 토큰 관측값은 완료 로그 사용량이나 비용에 더해지지 않습니다.

effort, tools 및 performance 프로필은 Trace를 조회하지 않습니다. not_requested 범위는 수집되지 않았다는 증거가 아닙니다. profile=tools만 userExact를 허용하며, 모든 Codex 인사이트 프로필은 modelExact를 거부합니다.
